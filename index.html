Features

接得进、记得住、看得懂屏幕

把接口接稳，把旧对话搬过来；再让每个角色记住你们聊过的事，能看懂你眼前的屏幕。

DeepSeek 官方接入

填官方接口地址和密钥，手机直连，不经过中转服务器；模型列表可拉取，随时切换。

对话导入

官方网页版导出的归档包整包吃进来，会话标题、消息、图片、时间戳原样还原。

日历管理

按月热力图铺开，哪几天聊得多一眼看出来；点日期直接筛出当天的会话。

图片与文档一起发

相册缩略图右上角圆点直接多选，PDF、文本一并塞进同一条消息。

联网搜索工具

搜狗结果卡片与 Bing 两路并行检索，按相关度合并去重，再抓网页正文；完整检索词不拆词，抓不到正文时保留引擎摘要。

本机运行 Python

内置 numpy / scipy / matplotlib，代码在手机上直接执行，计算结果和图表立刻出现在回复里。

问一句就翻历史

「上个月聊了什么」「addpath 那次说了啥」直接在本地按日期、按关键词查全量会话，真实原文作答。

深浅两套配色

浅色白卡配淡蓝，深色整屏压到 #191b20，附件、弹层、引用块逐个对齐。

密钥留在本机

接口密钥经系统密钥库封装后落盘，设置页不回显明文，导出包里不带凭据。

角色扮演与角色卡

内置角色直接切换；也可以导入标准角色卡，或把自己写的角色连同开场白、性格、场景和世界观一起导出。

角色记忆

每个角色一份独立记忆，一条记录一份 Markdown。新事实覆盖旧结论时，旧条标记过期保留；可查看全文、整理成档案、清理过期。

看屏幕与截图

说“看一下屏幕”或“截图”，先停住当前回复和朗读，播一段动效，再把当前画面作为附件交给模型分析；首次使用需开启系统读屏权限。

桌面宠物

悬浮球可以拖动、靠边停靠；光环颜色和动效跟随角色心情变化。桌宠卡片只留输入框与发送，拍照、截图直接在对话里说。

What's new · 3.11.47

角色卡扫码导入，桌宠能看屏幕

导入角色卡不再直接跳系统文件选择：相机预览扫码、相册识别、文件导入三条路；扫到后先预览再添加。桌宠说一句“看屏幕”会截屏并继续对话。

扫码导入

点导入先选方式；相机预览连续识别，扫到后显示角色信息，确认后写入。

相册识别

从相册选含二维码的卡片图，本地识别；文件入口只收角色卡与卡片截图。

卡片导出

按角色名生成文件名，可保存到手机或直接分享；可选是否带上角色记忆。

桌宠看屏幕

桌宠卡里说“看屏幕”，先停当前生成，截屏作为附件发出；截不到会明确提示。

悬浮球边界

调整悬浮窗与安全边距，状态栏、导航栏和刘海附近也能完整显示球与光环。

导入预览

扫码或文件导入都先显示名字、简介、作者、标签、世界观和记忆条数，再决定添加。
