# 小黑喵 MeowChat

安卓对话客户端。把接口、角色、记忆和桌宠收进一台手机：接 DeepSeek 官方接口直接聊，官方网页版导出的对话整包导入，按月回看每天聊过什么；角色各有独立记忆，也能读懂当前屏幕。

## 下载

[MeowChat 3.11.60](https://github.com/Alice-P197/meowchat/releases/download/v3.11.60/MeowChat-3.11.60.apk) · arm64-v8a · Android 8.0 及以上 · 162 MB

安装时允许「未知来源」，覆盖安装不会清空已有会话。

## 功能

- **DeepSeek 官方接入**：填官方接口地址与密钥，手机直连，不经过中转；模型列表可拉取、随时切换
- **角色扮演与角色卡**：内置角色直接切换，角色卡支持扫码、相册、文件导入，导出可保存或分享；开场白、性格、场景、世界观随卡保存
- **角色记忆**：每个角色独立记忆，一条记录一份 Markdown；冲突时旧结论标记过期保留，可整理成档案、清理过期
- **看屏幕与截图**：说一句“看一下屏幕”或“截图”，自动停住当前回复与朗读，截取画面作为附件交给模型分析
- **桌面宠物**：悬浮球可拖动、双击贴边缩小；罗小黑五种形态，抚摸随机切换，单击打开输入条，光环颜色随角色心情变化
- **对话导入**：官方网页版归档 zip 整包导入，会话标题、消息、图片、时间戳原样还原
- **日历管理**：按月热力图，点日期筛出当天会话
- **附件**：相册缩略图右上角圆点直接多选，PDF、文本可同时发送
- **深浅配色**：浅色白卡配淡蓝，深色整屏统一压暗
- **密钥**：经系统密钥库封装后落盘，设置页不回显明文
