# 小黑喵 MeowChat

安卓对话客户端。接 DeepSeek 官方接口直接聊，官方网页版导出的对话整包导入，按月回看每天聊过什么。

## 下载

[MeowChat 3.11.44](https://github.com/Alice-P197/meowchat/releases/download/v3.11.44/MeowChat.apk) · arm64-v8a · Android 8.0 及以上 · 70 MB

安装时允许「未知来源」，覆盖安装不会清空已有会话。

## 功能

- **DeepSeek 官方接入**：填官方接口地址与密钥，手机直连，不经过中转；模型列表可拉取、随时切换
- **对话导入**：官方网页版归档 zip 整包导入，会话标题、消息、图片、时间戳原样还原
- **日历管理**：按月热力图，点日期筛出当天会话
- **附件**：相册缩略图右上角圆点直接多选，PDF、文本可同时发送
- **深浅配色**：浅色白卡配淡蓝，深色整屏统一压暗
- **密钥**：经系统密钥库封装后落盘，设置页不回显明文
